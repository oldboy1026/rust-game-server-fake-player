# English documentation index

The main [README](../README.md), [application guide](../steam-multi-account/README.md), [code guide](CODE_GUIDE.md) and [research guide](RESEARCH.md) describe the project in English. The web interface has English and Chinese language options, including project background and research status.

This index maps all 67 historical research, tooling and deployment documents to their English editions. The original Chinese documents are retained. English editions preserve material findings, evidence links and limitations; some consolidate repeated chronological detail. Dates, account counts, endpoints and process states in historical reports describe those experiments. They are not current service state or instructions to restore old sessions. All previously imported accounts were deleted on 2026-10-27.

**Current evidence boundary:** independent admission has historical evidence on the configurations actually tested. No verified standalone Rust EAC-protected session or reproducible Facepunch public-population increase has been established. Modified A2S replies, internal player counts, plugin events, Steam validation and EAC cached flags are different observations. See [research direction](RESEARCH.md) for the verification criteria.

Raw account stores, credentials, captures, private rosters and local research dependencies are excluded from publication. Public JSON summaries referenced by reports contain selected sanitized evidence. An English report is documentation, not evidence that an experiment has been repeated.
