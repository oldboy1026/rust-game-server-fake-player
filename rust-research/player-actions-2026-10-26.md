# 单账号角色操作：实现、验证与限制

2026-10-26，目标游戏地址 `61.147.247.25:40176`，查询端口 `40177`。

## 页面操作

打开 `http://127.0.0.1:3210/rust`，在已入服账号一行点击“角色操作”。每次只控制该账号，不循环执行，不批量发送动作。

| 功能 | 当前行为 |
| --- | --- |
| 唤醒一次 | 完整自身快照支持时，发送中立、下蹲、释放三帧输入 |
| 死亡后重生 | 仅在新鲜的自身死亡快照和该实体 FinishLoading 后，发送一次普通 `respawn` 请求 |
| 自杀一次 | 必须勾选允许自杀；仅对新鲜的自身存活状态发送一次普通 `kill` 请求，服务器仍检查规则和冷却 |
| 停止动作 | 停止当前单账号动作；若已开始动作且无法安全释放输入，则关闭这个账号的 Rust 连接。空闲时不发包、不退出 |
| 前后左右短步 | 勾选确认平坦、无遮挡测试区域后，按当前自身视角偏航，每次最多 0.28 米，六帧含中立和释放 |
| 原地跳跃 | 同样需要确认测试区域；16 帧、最高 1.5 米、回到相同高度的实验轨迹 |
| 聊天 | 原有“发送聊天”按钮，人工输入文本；新增明确标记 `[测试]` 的问候预填，不自动发送、不模拟多人对话 |

除停止外，操作间隔至少五秒。动作前要求两秒内收到的、序列有效的完整自身快照；位置回声不能刷新健康、模型或快照年龄。睡眠角色不能直接行走/跳跃，需先唤醒并收到新的有效状态。旧快照下会明确拒绝，程序不会为了操作擅自重连账号。死亡后角色可能长期不更新完整快照，因此手动重生同样可能被这一限制阻止；该情况需要新快照，不能将历史死亡记录当作实时状态。

短步和跳跃尚未实现地图地形碰撞、CharacterController、斜坡、障碍、坠落、水中运动、载具或自定义重力。它们是供管理员在已确认空地进行的实验输入，**不是已验证可用于任意实服环境的正常客户端移动**。服务器纠正、实体替换、未知自身 RPC、调度停顿等会中止动作，必要时结束该账号连接；不持续发送猜测位置来抵消纠正。

## 接口和回执

`POST /v1/accounts/{id}/rust-action`，沿用 Bearer API key 和同源检查。

```json
{"action":"wake"}
```

```json
{"action":"forward","flatGround":true}
```

```json
{"action":"suicide","confirmDeath":true}
```

允许的 action：`wake`、`respawn`、`suicide`、`stop`、`forward`、`backward`、`left`、`right`、`jump`。不接受任意控制台命令、坐标、可执行文件、RPC 或原始报文。Python 输入线程仅校验、排队，原生调用全部在接收线程执行。

HTTP 202 返回该请求的工作进程回执，可能为 `started`、`sent`、`stale_state`、`unsupported_state` 等，必须读取 status。`serverConfirmed:false` 刻意保留。后续在账号会话 `metadata.lastAction` 中查询相同请求编号；`snapshot_observed` 只表示收到了与操作后状态相符的新完整自身快照，不是服务端命令成功确认，也不证明跳跃全过程或统计资格。五秒内没有匹配快照则记为 `unconfirmed`。工作进程关闭前不会提前取消其 Steam 票据；日志和回执不包含坐标、票据或聊天文本。

首个手动 Tick 后持续发送普通、无参数的自身连接维护 RPC。停止动作或确认超时不会停止连接维护；维护超时仍关闭连接。等级 0/1 走统一报文编码路径，EAC 消息及更高加密等级仍停止，`eacVerified=false`。
